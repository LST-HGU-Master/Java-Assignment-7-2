# 課題 7-2: インスタンスメソッドの追加

### 課題の説明
教科書のコード8-15を参考にMatangoクラスを作成しなさい。
ただし、Matangoクラスには以下の`selfDestruction`メソッドを追加すること。
また、実行例にあわせて Prog72 クラスの main メソッドを作成しなさい。

| メソッド名        | 戻り値の型    | 引数リスト        | 処理内容                              |
|--------------|----------|--------------|-----------------------------------|
| `selfDestruct` | なし(`void`)       | なし           | 「お化けキノコ<suffix>は自爆した！」と表示し、この Matango インスタンスの `hp` を `0` にする | 

### 実行例
お化けキノコAは逃げ出した！
お化けキノコBは自爆した！

（注意）感嘆符「！」および「お化けキノコ」の表記はすべて【全角文字】とすること。
